# MiniBanc

Mon mini-banc d'essai maison (PC + Arduino), le projet fil rouge de mon plan de formation LabVIEW.

## Contenu

| Fichier | Description |
|---|---|
| `Test_simu_banc.vi` | Banc simule : tension aleatoire 0-5 V, graphe deroulant, verdict OK/KO (3,0-3,6 V) et compteur de cartes OK (registre a decalage). |
| `Temp_Sensor_test.vi` | Test de capteur de temperature. |

## Outils

- LabVIEW 2026 Community Edition
- Digilent LINX (pilotage Arduino)
